# 语法说明编写标准

先保证正确，再降低学习成本。N5～N1 全部 388 张语法卡片采用本标准，由 336 份讲解覆盖普通体、礼貌体及表记变体。首批 N5「てください」、N4「そうだ（样态）」、N3「うちに」、N2「かねる」、N1「に堪えない」的样板内容保留。

## 列表卡片

- 保留一句核心释义、简短但不缺必要成分的接续、2～3 个日中例句。
- 首例优先展示基本结构，避免同时叠加复杂敬语或其他新语法。
- 例句按意义和场景覆盖选取，不以更换词类或重复同义句充数。
- 每句接续标签只描述该句实际使用的形式；例如「元気なうちに」必须包含「な」。

## 详情

- 核心意思：解释何时使用、表达什么，避免把整个语义类别的功能归给某一个句型。
- 接续与构成：列出本条适用的形式和实际变形，不重复解释斜线、V、N 等通用符号；形容词统一用术语浮窗支持的「い形」「な形」。
- 常见用法：按不同意义或真实使用场景拆分；每项紧跟例句、中文翻译和一句解析。
- 易错点与比较：指出错误位置或语义区别。只给实际语法错误加 `verdict: 'incorrect'`，中文写成“想表达：……”；正确但含义不同的句子不能打叉。
- 特殊情况：只收录对本条有用的例外或变体，配例句。没有需要单列的情况就保留空数组，页面自动省略栏目。
- 例句的 `focus` 必须是日文原句中的片段，页面据此突出目标结构。
- 限定词要准确：区分“不能”“通常不”“在这个语境不自然”，不把教学上的常见搭配写成没有例外的规则。
- 每条在 `references` 保存公开教学资料或词典来源。具体页面用于核对相应规则，课程目录用于延伸查阅，不能把目录链接视为逐句审核证明。例句为项目编写，不整段搬运教材。

## 数据与兼容

`data/grammar-lessons-n5.js` ～ `data/grammar-lessons-n1.js` 保存全部显式编写的内容，是页面语法释义、接续、列表例句和详情的编辑入口。按首个 ID 所在等级分文件；同一讲解的变体可能跨等级。基础数据继续定义卡片目录、标题、ID 和顺序，早期例句文件仍保留，但最终显示内容由新的讲解覆盖。

`data/grammar-lessons.js` 在上述文件和早期例句之后加载，先检查所有卡片都有且只有一份讲解，再应用内容。`ids` 将同一语法的普通体、礼貌体或汉字／假名变体绑定到同一份内容，保留各卡片 ID 和学习进度，不做进度迁移。新增语法时必须同时添加目录条目和讲解，并更新校验中的规模断言。

详情 `version: 2` 使用 `formationRows` 与包含场景例句的 `usages`、`cautions`、`specialCases`。后两者允许为空，不设凑数条目要求。列表例句与详情例句独立，扩充讲解不会把列表卡片拉长。

`grammar-details-renderer.js` 对所有字段按文本转义，现有卡片全部使用新格式。旧版通用详情文件已移除，页面不再加载重复的模板解说，也不在运行时套模板造句。

运行 `node scripts/check-grammar-lessons.cjs` 检查脚本顺序、388 张卡片完整覆盖、规则与例句关联、目标片段、变体一致性、目录与词汇不变、空栏目与文本转义。提交前还应运行 Pages 工作流中的完整数据检查。程序检查不能替代日语内容审核；仍需逐句核对日文、中文、接续及语境。
